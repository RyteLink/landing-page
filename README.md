# RyteLink — Official Landing Page

Premium marketing website for **RyteLink** — consumer electronics, product sourcing & wealth solutions across Africa.

## Overview
* **Clean Piggyvest-Style Aesthetics**: High-contrast, minimal layout focusing on White and Black with tasteful Orange accents.
* **Core Offerings**:
  * North American Fast-Moving Consumer Electronics Sourcing.
  * Trade Cycle Financing with Instant Upfront Interest (Day 1 payouts to commercial banks).
  * 3-Month Capital Maturity & Reinvestment.
  * Multi-Tier KYC & Security Rails (256-Bit SSL, Anchor BaaS custody, Paystack gateway).
* **Live Features**:
  * Real-time Interactive Trade Returns & Maturity Calculator.
  * Dynamic Trade Cycle Tranche Selection (3 Months vs. 6 Months).
  * FAQ Accordion with verified regulatory and operational answers.
  * Mobile and desktop responsive design with smooth lazy loading.

## Deployment
Static HTML5, CSS3 (Vanilla), and Vanilla JavaScript — ready for instant deployment on Netlify, Vercel, or GitHub Pages.
